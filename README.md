# Signals

**Gaming is no longer just playing.** 19 short minigames about how teens
connect today. Each level is a *signal*: a small truth about friendship,
culture and belonging.

▶ Play: https://helenapastranaproducciones.github.io/Signals/

**Helena:** la teva guia és [GUIA-HELENA.md](GUIA-HELENA.md).

## Run it locally

Requires Node 20 or newer. There are no dependencies to install.

```bash
npm start      # http://localhost:8000
npm test       # unit tests
npm run status # how far each level is
```
